# Práctica de clase — 2026-09-14

Ejercicios resueltos durante una sesión de práctica de maratón de programación (UAM).

| Archivo | Descripción |
|---|---|
| [`cuantos_numeros_triangulares.py`](cuantos_numeros_triangulares.py) | Dado un rango `[num, num2]`, cuenta cuántos números triangulares (1, 3, 6, 10, …) hay dentro de ese rango, despejando la posición `k` a partir de `n = k(k+1)/2`. |
| [`dora_exploradora_ii.py`](dora_exploradora_ii.py) | Dadas unas coordenadas `(x, y)`, calcula el valor que le corresponde en una matriz numerada por diagonales en zigzag. |
| [`hmsequence.py`](hmsequence.py) | Dado un número `n`, calcula `ceil(sqrt(n))`, la posición correspondiente en la secuencia. |
| [`imanes.py`](imanes.py) | Dada una lista de orientaciones de imanes, cuenta cuántos grupos quedan al fusionar los imanes consecutivos con la misma orientación. |

Todos los programas leen su entrada por `stdin` siguiendo el formato típico de los jueces de maratón (uno o varios casos de prueba, terminando en un valor centinela como `0` cuando aplica).
