# Maratón de Programación

Ejercicios que voy resolviendo en clases de maratón de programación y en competencias. El repositorio se organiza por evento/sesión, cada uno en su propia carpeta con un breve README describiendo los ejercicios que contiene.

## Estructura

Cada carpeta sigue el patrón `AAAA-MM-DD-nombre-evento` (o `AAAA-nombre-evento` cuando no aplica una fecha exacta) y contiene:

- Las soluciones (`.py` u otro lenguaje, según el caso).
- Un `README.md` con una tabla resumiendo qué hace cada ejercicio.

## Ejecución

Los ejercicios están mayormente en Python 3 y leen la entrada por `stdin`, siguiendo el formato habitual de los jueces de maratón. Por ejemplo:

```bash
python3 2026-09-14-practica-clase/imanes.py < entrada.txt
```
